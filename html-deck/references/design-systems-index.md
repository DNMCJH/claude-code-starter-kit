# Design Systems Index — 68 Brand Aesthetics Quick Reference

Quick-reference catalog of 68 brand design systems for picking a visual direction when building decks, landing pages, or UI. Each row: brand, one-line aesthetic, and the source DESIGN.md (full tokens at the link).

**How to use:** "I want a Linear-style minimal feel" -> find the row -> apply its palette/type direction. For the full token set (CSS variables, type scale, components), download the linked DESIGN.md (built for Claude Design at https://claude.ai/design, but the tokens are portable to any HTML/deck work).

Source: VoltAgent/awesome-claude-design (https://github.com/VoltAgent/awesome-claude-design), MIT. Curated starting points inspired by publicly observable patterns; not official brand systems.
